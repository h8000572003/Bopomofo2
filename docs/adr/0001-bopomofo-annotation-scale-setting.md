# 注音標注字級以「相對階梯 + 頂端封頂」的使用者設定實現

`BopomofoRuby` 各呼叫端原本各自寫死一個結構性 `size`（`sm`/`md`/`lg`/`xl`），注音標注（聲母/介音/韻母/聲調）字級遠小於漢字，對目標使用者（幼兒園大班~國小低年級）而言偏小難以辨識。我們沒有直接調大 `sizeConfig` 的絕對數值，而是新增一個持久化、三段式（標準/大/特大，預設「大」）的「注音字級設定」，只作用於注音標注、不影響漢字大小，且以「相對階梯」方式運作：每上一階，該呼叫端就套用既有梯子（`sm→md→lg→xl`）中下一格的注音字級數值，在已經是 `xl` 的呼叫端（目前只有全螢幕翻卡片）則封頂、不再往上，不會為此發明未經視覺驗證的全新尺寸。

## Considered Options

- **絕對倍率**（放棄）：不論呼叫端原本選哪個 `size`，一律套用同一組固定數值。放棄原因：會蓋掉各畫面原本刻意設計的相對大小關係（例如密集網格卡片的注音可能因此比全螢幕翻卡片還大）。
- **延伸梯子到 `xl` 之上**（放棄）：讓「特大」等級在 `xl` 之上再加兩級全新數值，使翻卡片也能繼續變大。放棄原因：翻卡片本來就是全站最大版面、注音已是最大字級，沒有「太小看不清楚」的問題，延伸梯子只是為了理論一致性而引入未經測試的視覺尺寸。
- **寫死調整 `sizeConfig`，不做成設定**（放棄）：實作最簡單，但使用者明確希望這是可調整的設定（比照既有語速設定模式），而非固定值。
