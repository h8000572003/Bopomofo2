# 3D 字卡背面新增發音與麥克風跟讀測試，正面維持 ADR-0002 不變

字卡正面依 [ADR-0002](0002-flashcard-front-hides-hanzi.md) 完全不提供任何發音提示，逼孩子先靠注音自拼；但這也連帶讓整個 3D 字卡功能完全沒有地方能聽到單字本身的發音（背面原本只有例句朗讀）。我們把「整詞發音」「逐字發音」與麥克風跟讀測試都加在**背面**（翻牌看到正確漢字答案之後），而不是加回正面——正面保持「先猜、零提示」，背面補上「核對答案＋聽發音＋自己跟讀練習」，兩者合起來才是完整的學習流程，也不需要推翻剛做的 ADR-0002。

刻意採取精簡版，不比照 `WordDetailModal` 的完整聲母/介音/韻母拆解＋標準/慢速雙速度發音：字卡的核心互動已經是整詞層級的「看注音猜字」，不需要在背面重做一次單字探索功能已經在做的深度拆解教學。

麥克風跟讀測試只測**整詞**發音（不逐字分開測），且成功時只在 `MicRecorder` 元件自身顯示星等評分作為即時回饋，不呼叫任何持久化 callback（不加真實星星、不自動標記「已記住」）——字卡的「已記住」清單是使用者自己判斷後手動勾選的，刻意不讓機器的發音辨識結果去動這個清單，避免「發音對但其實還沒認得字形」污染記錄。
