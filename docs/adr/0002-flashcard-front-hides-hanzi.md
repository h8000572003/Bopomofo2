# 3D 字卡正面永久隱藏漢字，注音放大填滿整塊區域（ADR-0001 的明確例外）

`FlashcardDrillView` 的正面原本是「大漢字（`text-7xl`）＋緊貼的小注音」，背面才是解答。我們改為正面**永久**（非可切換模式，不做開關、不持久化設定）不顯示漢字，注音標注直接放大填滿原本漢字所在的整塊區域，成為正面唯一的主要視覺內容；點擊字塊也不再播放發音提示。翻到背面才會看到完整漢字、字義與例句。

這違反了 [ADR-0001](0001-bopomofo-annotation-scale-setting.md) 訂下的「注音標注沿既有梯子相對放大、在 `xl` 封頂、絕不追上漢字大小」的規則——但 ADR-0001 的前提是「注音标注緊貼著一個同時顯示的漢字」，用來維持兩者的相對比例；字卡正面現在**沒有漢字可以比例對照**，注音本身就是正面的全部內容，因此不適用同一套比例邏輯，也不受該規則的 `annotationScale` 全域設定影響，是它的一個限定範圍例外，而非取代或修改 ADR-0001 本身。

這個決定刻意犧牲了「點擊聽發音」的提示功能（見 Q4 討論），目的是讓孩子必須先靠注音符號自己拼讀出音、猜出漢字，翻到背面才能核對答案，強化「先猜後驗」的學習流程。
